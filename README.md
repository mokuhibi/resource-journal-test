# 育成リソースノート（テスト版）

アメとゆめのかけらを記録・集計する、スマートフォン向けWebアプリです。

[テスト版を開く](https://mokuhibi.github.io/resource-journal-test/)

## 使い方

1. 編成 → 新規登録でポケモンを登録し、チームの5枠へ設定します。
   にとよんさんの「個体値計算機 for ポケモンスリープ」のCSV／TSVは、新規登録の「個体値計算機から取り込む」から読み込めます。保存前に内容と重複候補を確認できます。
2. 記録で日時を確認し、アメやゆめのかけらを記録します。
3. アメ・ゆめのかけらで集計、履歴で詳細・訂正・削除ができます。
4. 設定 → データの「保存」でCSVバックアップ、「復元」で読み込みできます。

## 保存について

記録は使用中の端末・ブラウザのlocalStorageに保存されます。ログインや端末間の自動同期はありません。プライベート閲覧やサイトデータの削除に注意し、定期的にCSVを保存してください。CSV復元は現在のデータを置き換えるため、必要なデータは先に保存してください。

同じGitHub Pagesドメイン上の別パスでも、同じブラウザでは保存領域を共用します。URLの違いだけで記録は分離されません。別ブラウザ・別端末への移行にはCSVを使用してください。0個のスキル発動も保持します。

このリポジトリは確認済みのテスト版だけを公開します。開発履歴・利用者の記録・バックアップは含みません。開発用からの自動同期は行いません。
